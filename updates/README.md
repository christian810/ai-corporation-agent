# Paquetes de actualización

Cada ZIP es una versión construida y probada. La sede debe aprobar una URL fijada a un commit completo junto con su SHA-256 y tamaño antes de que los equipos la instalen. Cambiar archivos del repositorio no autoriza por sí solo una actualización.

No incluir configuraciones, claves, resultados empresariales ni registros. Consulta ../ACTUALIZACIONES.md.
